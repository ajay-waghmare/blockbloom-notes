## Gotcha found while publishing Arrow Bloom (affects Block Bloom)
- Play API `tracks.update` replaces the whole release list of a track. A PUT that contains only a new draft dropped the live `completed` release inside the edit (Arrow Bloom dry run, 20 Oct). Block Bloom's `tools/play-upload.js` sends only the draft: before its next use on a track with a live release, dry-run and read the track back, or switch to Arrow Bloom's `tools/play-stage-draft.js` pattern (carry live releases over, refuse to commit if one vanishes). Memory: `reference_play_api_track_update_gotcha.md`.
