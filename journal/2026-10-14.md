## Done today (vc23 / 1.12.0)
- **Google Play In-App Updates Integration (Option B)**:
  - **Dependency**: Added `com.google.android.play:app-update:2.1.0` in `app/build.gradle.kts`.
  - **Architecture (`InAppUpdateHost`)**:
    - Created `InAppUpdateHost` interface and production `PlayInAppUpdateHost` wrapping Google Play's `AppUpdateManager`.
    - Implemented `AppUpdateType.FLEXIBLE` non-blocking flow: checks for update availability silently on app launch and activity resume without interrupting gameplay.
    - Added download listener for `InstallStatus.DOWNLOADED` to seamlessly transition UI into a ready-to-restart state.
    - Graceful fallback: If in-app flow cannot start, automatically opens the Play Store listing via market/web intent.
    - `NoOpInAppUpdateHost` provided for unit tests and local previews.
  - **UI Integration (`UpdateBanner`)**:
    - Created `UpdateBanner.kt` composable using modern theme tokens (`BrandTeal`, `SurfaceCard`).
    - Integrated on `HomeScreen`: Renders between stat chips and the Hero Play button when an update is available.
    - Integrated on `SettingsScreen`: Renders cleanly above the version footer.
    - When downloaded: Automatically transitions from "New update available · Update now" to "Update ready · Restart" calling `completeUpdate()`.
  - **ViewModel Integration (`GameViewModel`)**:
    - Added `updateAvailable` and `updateDownloaded` state properties to `GameState`.
    - Added `checkInAppUpdate()` on init and `onActivityReady()`.
    - Added `startInAppUpdate()` initiating update via bound activity.
    - Added lifecycle cleanup in `onCleared()`.
  - **Localization**: Added full native translations for all update banners across 7 languages (`en-US`, `de-DE`, `es-ES`, `ja-JP`, `ko-KR`, `pt-BR`, `tr-TR`).
  - **Testing**:
    - Added `InAppUpdateHostTest.kt` verifying contracts, null safety, and full flexible update lifecycle transitions.
    - Ran `:app:testDebugUnitTest`: 32 tasks executed, **BUILD SUCCESSFUL**.
    - Ran `:app:assembleDebug`: 43 tasks executed, **BUILD SUCCESSFUL**.

## Decisions
- Chose Option B (Google Play Flexible In-App Update API with non-blocking banner) over hard-blocking force update (Option A) to avoid player drop-off or uninstalling while actively migrating legacy 1.10.0 users.
