## 🧭 Memory Operating Rules

1. **Dedicated Topic Files:** Whenever a new major app, commercial initiative, or life/personal topic is introduced, spawn a new `topic_<name>.md` file. Never merge unrelated domains into a monolithic file.
2. **Always Pushed to GitHub:** Every memory update must immediately be committed and pushed to `blockbloom-notes` on branch `journal`. It must never remain solely in local machine state.
3. **Ground Truth Only:** Record exact versionCodes, transaction dates, URLs, package names, policy deadlines, and verified metrics. No speculation or ungrounded estimates.
